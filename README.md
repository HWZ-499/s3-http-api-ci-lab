这是隔离实验副本，不是原仓库补丁。只使用 Python 标准库。

**业务预期**：本机 HTTP API 应在 `127.0.0.1:18080` 提供 `/documents/{id}` 接口；原有 8 条权限测试应该全部通过。

**故障任务**：当前实验副本存在一个预设故障。不要从原项目复制修复，也不要重写业务授权规则。先通过终端和文件证据判断故障所在层次，再尝试最小修复。

## 运行

1. 在 VS Code 中单独打开解压后的 `s3_1_fault_lab` 文件夹。
2. PowerShell 终端 A：`python http_identity_lab.py`；保持运行（若报错，保留完整输出）。
3. PowerShell 终端 B：`curl.exe -i --max-time 5 http://127.0.0.1:18080/documents/42`。
4. 提交这两个终端的实际结果，以及你认为下一步最有区分度的一项检查。**此时不要自行改代码**。

**边界**：本实验不用管理员权限，不需要 Docker，不执行任何真实外部业务操作；预期端口是 `18080`，不会影响原项目使用的 `8000` 端口。若目标端口已有其他服务，请保留端口检查结果，不要盲目结束进程。

后续在定位完成后运行：`python -m unittest -v test_document_http`，再按原有业务规则确认 8 项回归。
